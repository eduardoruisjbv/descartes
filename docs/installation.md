# Installation

No installer is provided. In a skill-capable platform, use its documented installation procedure, placing `SKILL.md` and `references/prompt-template.md` in the skill’s configured directory. Otherwise, include `SKILL.md` as instructions and consult the reference template when preparing prompts. The phrase “cogito, ergo sum” can be a conversational invocation convention only where a user chooses; automatic phrase activation is platform-specific and not guaranteed.
